## Synthetic enterprise-to-equity bridge check

The class synthetic check uses hypothetical values:

- Enterprise value: $1,000 million
- Add: non-operating assets: $100 million
- Less: debt: $(250) million
- Less: debt-like claims: $(20) million
- Less: non-common claims: $(10) million
- Equity value: $820 million

Calculation:

Equity value = $1,000M + $100M − $250M − $20M − $10M = $820M

Per-share value = $820M / 100M diluted shares = $8.20 per share

## Cadence filing-based bridge

The Cadence 10-K does not state enterprise value. Using filing data in millions:

Equity value = Enterprise value + cash − debt − debt-like claims − non-common claims

Core bridge, excluding operating leases:

Equity value = EV + $3,001.317M − $2,480.150M − $0M

Equity value = EV + $521.167M

Per-share value = (EV + $521.167M) / 273.312M diluted shares

Alternative bridge, treating operating lease liabilities as debt-like:

Equity value = EV + $3,001.317M − $2,480.150M − $186.178M − $0M

Equity value = EV + $334.989M

Per-share value = (EV + $334.989M) / 273.312M diluted shares

Cadence reported no preferred stock outstanding, so non-common claims from preferred stock equal $0.
