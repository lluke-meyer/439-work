[00:12] Luke Meyer: This repository supports a reject-or-redesign decision for an investment

[00:42] Luke Meyer: The repository has four main Python files. `portfolio.py` contains the
portfolio calculations and constrained search. `market_data.py` handles the optional public Yahoo
Finance monthly pull. `backtest.py` contains the lagged, cost-adjusted development and holdout
calculation. `app.py` is the Streamlit interface that calls the engines. The tests folder checks the
known-answer model, live-data adapter shape, and application rendering, while `outputs` contains the
visible executed result.

[01:22] Luke Meyer: The bundled or live price history becomes monthly returns, annualized estimates,
correlations, and covariance. The default bounded-short policy uses ten-point allocation steps so
the app stays usable. The theme audit runs all ten six-fund starting universes under the same return,
reserve, ticker, gross-exposure, and overlap controls. Equal-weight and inverse-volatility baselines
use the same estimates and receive the same visible mandate verdict. Derivative hedging is disclosed,
but contract-level risk is outside this price-only engine.

[02:17] Luke Meyer: The backtest applies the signal lag before selecting a position, charges the
switch cost, and reports development and holdout gross and net results against buy-and-hold. The
one-month lag and 0.10% switch cost are preserved as the frozen classroom result; the sidebar
controls run bounded sensitivity scenarios without retuning the holdout.

[03:07] Luke Meyer: A clean user can run the application with Streamlit or run the test suite with
`python -m unittest discover -s tests -v`. The visible output shows the current inputs, data source,
theme audit, baseline verdicts, allocation, and holdout result without requiring the grader to infer
the decision from source code.

[03:57] Luke Meyer: The highest-risk limitation is the reserve classification. Removing the TLT
