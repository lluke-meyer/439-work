[CAMERA — OPENING]

This repository supports
a WATCH-AND-DEFER decision
for a committee
with no current C-D-N-S position.

The highest-risk claim is that
the current market price
is not supported—
even after giving Cadence
credit for growth.

That claim could be wrong
because of a finance convention,
a stale or mismatched data input,
or a technical failure
in the linked statements
or valuation bridge.

//

[SHOW REPOSITORY]

The repository has
two main application files.

Project-one-model dot pie
contains the finance logic,
while app dot pie
is the Streamlit interface.

The tests folder
checks the model and application.

Outputs contains
the frozen visible result
and validation evidence.

Docs contains
the research evolution,
decision memo,
and validation record.

Requirements dot text
defines the runnable environment,
while the Read-Me
gives the clean-user setup
and reproduction commands.

//

[SHOW BASE INPUTS AND FORECAST]

In project-one-model dot pie,
the base inputs begin with
Cadence's fiscal-year twenty-twenty-five
opening financials
and explicit forecast assumptions.

The named downside,
base,
and upside cases
use the same model structure.

The forecast links revenue,
gross profit,
operating expenses,
taxes,
working capital,
capital spending,
depreciation,
debt,
equity,
and cash.

Cash is the balancing item,
and the model separately checks
both the balance sheet
and cash-flow statement.

//

[SHOW DCF AND DECISION ENGINE]

The forecast then calculates F-C-F-F
and discounts it
using the selected WACC.

Terminal growth
must remain below WACC.

Enterprise value
is bridged to equity value
by adding cash,
subtracting debt,
and dividing by diluted shares.

The committee decision function
applies one disclosed rule
to the calculated value.

Initiate only with
a fifteen-percent margin of safety.

Watch and defer
above the modeled downside floor.

And do not initiate
at or below that floor.

A failed integrity check
stops the decision.

//

[SHOW EXTENDED FUNCTIONS]

The newer functions extend
that same core.

The market-expectations dashboard
solves for the revenue-growth shift,
WACC,
or gross margin
required to reach the market price.

The semiconductor regimes
move operations
and beta together.

The Hexagon function
values the acquisition
as a separate incremental overlay,
so the fiscal-year twenty-twenty-five
statements are not silently mixed
with post-acquisition assumptions.

//

[SHOW APP DOT PY]

App dot pie
imports those functions
and presents their outputs.

It does not recreate
the valuation logic.

Changing a sidebar input
sends a new input set
through run-model,
and the displayed action
comes from the calculated result.

This separation lets
the same model drive
the interface,
the visible text output,
and the tests.

//

[SHOW TERMINAL]

A clean user can reproduce
the frozen result
with the snapshot command,
then run the unit-test command.

The current suite
contains sixteen tests
covering statement articulation,
scenario ordering,
WACC and terminal-growth direction,
the enterprise-to-equity bridge,
the committee engine,
market-price reconciliation,
industry regimes,
acquisition behavior,
and application rendering.

//

[RUN FAIL-LOUD TEST]

The highest-risk boundary test
is terminal growth
reaching WACC.

I will demonstrate it here
using the fail-loud control.

Instead of returning
an extreme or undefined valuation,
the model stops
with the expected error
that terminal growth
must remain below WACC.

The companion sensitivity test
also confirms that
increasing WACC
from ten percent to eleven percent
lowers value
from eighty-three dollars
and thirty-four cents
to seventy-two dollars
and ninety cents—

without changing
the operating forecast.

//

[CAMERA — LIMITATIONS]

The main unresolved limitation
is not hidden in the code.

The Hexagon section
is an acquisition-economics overlay—
not a full post-acquisition
three-statement rebuild.

Its transaction facts are sourced,
but revenue,
margins,
synergies,
integration costs,
reinvestment,
and deal WACC
remain analyst assumptions.

Synopsys is also
the only admitted peer.

Those limitations are why
the final action is conditional,
and why the model specifies
what evidence must be updated
before the committee reconsiders.
