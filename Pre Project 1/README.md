# Pre Project 1 Labs

This folder contains the lab progression that led into Project 1.

- `Lab04/` — initial Project 1 decision and evidence baseline.
- `Lab05/` and `Lab06/` — discounted cash-flow development.
- `Lab07/` and `Lab08/` — comparable-company development.
- `Lab09/` and `Lab10/` — pro-forma modeling and assumptions.
- `Lab11/` — one-at-a-time sensitivity analysis.
- `Lab12/` — valuation-method reconciliation and presentation output.
- `Supporting Research/` — unique CDNS research files that support the lab sequence but are not a
  second copy of a submitted lab.
