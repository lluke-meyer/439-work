# Post Project 1 Labs

All FIN 439 labs after Project 1 belong in this folder using one subfolder per lab:

```text
Post Project 1/
  Lab13/
  Lab14/
  Lab15/
  ...
```

Each lab folder should contain one consolidated record plus only the required code and source data.
Keep validation inside the runnable code when practical. Do not create separate README, trace,
saved-output, disclosure, or optional-challenge files unless the course specifically requires them.
Do not place new lab work in `Pre Project 1` or `Project 1`.
